# QuACS repository preferences

- For `quacs/quacs`, always squash and merge pull requests.
- The user grants standing authorization to use admin merge in this repository once CI passes.
- This admin merge authorization applies only to QuACS, not other repositories.

## Image uploads

- Before uploading or committing images to GitHub or any external service, remove personal metadata, including EXIF/GPS, XMP, IPTC, and comments.
- Verify that the cleaned copies contain no personal metadata before publishing them. Preserve image pixels and color interpretation where possible; avoid unnecessary re-encoding.
- Keep the user's original files unchanged and publish only the cleaned copies.
